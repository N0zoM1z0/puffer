Workflow:
1. Read `fuzz/README.md`, `fuzz/agent_guide.md`, and `fuzz/playwright_adapter.md`.
2. Run:
   `node fuzz/bin/puffer-fuzz.mjs validate`
3. Generate a frontier/plan:
   `node fuzz/bin/puffer-fuzz.mjs frontier --out /tmp/puffer-fuzz-frontier.md`
   `node fuzz/bin/puffer-fuzz.mjs plan --profile core --out /tmp/puffer-fuzz-plan.md`
4. Pick high-priority core seeds first. Start with:
   - `chat-turn-race`
   - `workspace-session-race`
   - `provider-auth-model-race`
   - `modal-focus-race`
5. For each selected seed, run:
   `node fuzz/bin/puffer-fuzz.mjs run --seed <seed> --iterations 30 --steps <seed-appropriate-steps> --rng-seed <unique-run-name> --out /tmp/puffer-fuzz-<seed>.json`
   `node fuzz/bin/puffer-fuzz.mjs report --input /tmp/puffer-fuzz-<seed>.json --out /tmp/puffer-fuzz-<seed>.md`
6. Pick the highest-value replay cases from the report, especially cases covering stale events, reconnects, duplicate submits, pending state, session switching, modal focus, or provider/model mismatches.
7. Generate temporary Playwright replay specs:
   `node fuzz/bin/puffer-fuzz.mjs replay --input /tmp/puffer-fuzz-<seed>.json --case-id <case-id> --out apps/puffer-desktop/tests/<case-id>.tmp.spec.ts`
8. Run replay specs:
   `cd apps/puffer-desktop && npx playwright test tests/<case-id>.tmp.spec.ts --workers=1 --reporter=list`
9. If a replay fails, rerun it at least 2 more times to check stability.
10. Shrink the repro mentally or by creating a smaller temporary probe only if needed. Do not leave temporary specs in the repo.
