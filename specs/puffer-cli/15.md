# MCP JSON HTTP Target Import

`puffer mcp add-json` accepts HTTP and SSE MCP server JSON that uses `target` as
the endpoint URL.

For non-stdio transports, when `endpoint` is empty and `target` contains a URL,
the CLI normalizes that URL into `endpoint` before validation and writes the
stored manifest in the same shape as `puffer mcp add --transport http`.

This preserves stdio behavior: stdio JSON still uses `target` as the command
line and requires it to be non-empty.
