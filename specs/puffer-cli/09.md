# Daemon Home Path Expansion

Desktop-originated daemon RPCs may pass user-entered paths containing `~`.
The daemon normalizes leading home shorthands before filesystem operations.

Contract:

- `create_session.cwd` expands `~`, `~/...`, and `~\...` before ensuring the
  session working directory.
- `git_clone.dest` expands the same leading home shorthands before destination
  validation and clone execution.
- `pty_open.cwd` expands the same leading home shorthands before opening a
  terminal in the requested directory.
- Relative paths without a leading home shorthand remain relative to the daemon
  workspace.
- If no home directory is available, the raw path is preserved.

Regression coverage lives in
`create_session_expands_home_cwd` and
`home_paths_expand_before_daemon_filesystem_operations`.
