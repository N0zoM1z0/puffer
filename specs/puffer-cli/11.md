# MCP Empty Target Validation

`puffer mcp add` and `puffer mcp add-json` reject manifests that cannot launch
or connect to an MCP server.

Contract:

- `stdio` MCP entries require a non-empty command target.
- `http` and `sse` MCP entries require a non-empty endpoint URL.
- Validation happens before writing the YAML manifest.
- Rejected inputs leave the target MCP resource directory unchanged for that
  server id.

Regression coverage lives in
`mcp_add_rejects_empty_targets_before_writing_manifest`.
