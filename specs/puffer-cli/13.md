# Browser Tab Close Unknown Tab Handling

`puffer browser tab close <tab-id>` rejects unknown tab ids instead of returning
the unchanged tab list as a successful operation.

The validation happens in the daemon browser registry before the backend page
session is closed. A close request now succeeds only when the requested tab is
present in the session tab registry. Requests for missing tabs return a
non-zero CLI status with a `no browser tab` diagnostic.

This preserves the existing behavior for `puffer browser tab close` without an
explicit tab id: it still closes the active tab, or the first tab when no tab is
marked active, and reports `no browser tabs for session` when the session has no
tabs.
