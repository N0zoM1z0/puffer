# Desktop MCP Endpoint URL Validation

The desktop daemon MCP management RPCs validate HTTP and SSE endpoint URLs before
writing workspace or user MCP manifests.

Affected RPCs:

- `add_mcp_server`
- `update_mcp_server`
- `test_mcp_server`

For `transport: http` and `transport: sse`, endpoints must be absolute
`http://` or `https://` URLs with a host. Invalid values fail before a manifest
is created or replaced. `test_mcp_server` also rejects existing malformed
HTTP/SSE manifests so users get the error at validation time instead of later
tool execution.

`stdio` behavior remains unchanged and continues to require a non-empty command
target.
