# Daemon MCP Duplicate IDs

The daemon refuses to create an MCP server whose ID already exists in the
loaded resource set.

Contract:

- `add_mcp_server` validates the requested ID against workspace, user, and
  builtin MCP resources before writing a manifest.
- Duplicate checks are case-insensitive.
- A duplicate request fails without overwriting the existing manifest.
- Successful non-duplicate adds keep returning the refreshed MCP server list.

Regression coverage lives in `add_mcp_server_rejects_duplicate_id`.
