# MCP HTTP Endpoint URL Validation

`puffer mcp add` validates HTTP and SSE MCP endpoints before writing a manifest.

For `transport: http` and `transport: sse`, the command now requires the
endpoint to be an absolute URL with an `http` or `https` scheme and a host. Empty
endpoints and relative paths are rejected before any YAML file is created.

`stdio` validation is unchanged: stdio MCP servers require a non-empty command
line and continue to accept command names plus optional arguments.
