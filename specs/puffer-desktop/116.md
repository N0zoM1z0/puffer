# Pipeline Tools Input Validation

- Area: Corbina desktop Pipelines selected-agent editor
- Change: the Tools field preserves raw user input and validates comma-separated values before updating the workflow tools array.
- Compatibility: simple comma-separated tool lists continue to update the workflow immediately when valid.

## Design

The selected-agent Tools input now keeps a per-node text draft instead of deriving every keystroke directly from the normalized tools array. Input is parsed as a small quoted comma list. Empty entries, trailing commas, misplaced quotes, and unclosed quotes render inline validation errors and do not overwrite the node's last valid tools.

Quoted values can contain commas, so a value like `"read,edit", bash` remains visible as typed while the workflow receives the parsed tools.

## Regression

`pipelines-ui.spec.ts` verifies that `read,,bash` is preserved with an inline validation error, and that a quoted comma value remains visible and survives provider switching.
