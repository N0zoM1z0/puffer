# Settings MCP Duplicate IDs

The Settings MCP form prevents users from adding a server with an ID that is
already visible in the current resource roster.

Contract:

- The MCP add form compares the trimmed ID against loaded server IDs
  case-insensitively.
- A duplicate ID shows an inline warning and disables `Add server`.
- The form must not send `add_mcp_server` while the duplicate warning is
  active.
- The daemon remains the final duplicate-ID authority for direct RPC callers.

Regression coverage lives in
`apps/puffer-desktop/tests/settings-ui.spec.ts`.
