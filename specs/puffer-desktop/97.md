# Desktop Home Path Expansion

Desktop workspace and project entry points accept the same leading home
shorthands users type in shells.

Contract:

- Switching the local workspace expands `~`, `~/...`, and `~\...` before
  restarting the local daemon.
- Git clone destination validation expands the same leading home shorthands
  before resolving paths against the selected base directory.
- Non-home relative paths keep their existing relative-path behavior.
- The daemon remains responsible for final path normalization before session
  creation or clone execution.

Regression coverage is split between frontend validation and the daemon
`home_paths_expand_before_daemon_filesystem_operations` test.
