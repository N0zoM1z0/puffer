# Terminal Active Close Input Detach

## Summary

The Terminal pane now detaches the old xterm input handler immediately when the
active PTY tab is closed.

## Behavior

- Closing the active terminal tab removes the old terminal attachment before
  focusing or replaying the next PTY.
- Keyboard input during the async switch cannot be written to the closed PTY.
- The next PTY still activates and attaches normally after its focus/replay
  work completes.

## Compatibility

Closing inactive terminal tabs is unchanged. Closing the active tab with another
tab available now has a brief detached transition instead of keeping stale input
bound to the closed PTY.
