# Stop Turn Session Guard

Stop-turn request results are scoped to the session that submitted the
cancellation.

Contract:

- Stop-turn submissions capture the selected session id and session-load
  generation before dispatching `cancel_turn`.
- A delayed stop success updates status only if the same session remains
  selected.
- A delayed stop failure appends retry/error UI only if the same session
  remains selected.
- Switching sessions while `cancel_turn` is pending must not add stop-failure
  rows to the newly selected transcript.

Regression coverage lives in
`apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
