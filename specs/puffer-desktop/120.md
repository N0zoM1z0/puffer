# Pipeline JSON Export Action

- Area: Corbina desktop Pipelines editor
- Change: the Pipelines toolbar now exposes a `Copy JSON` export action for the active workflow draft.
- Compatibility: this is a local export action only; daemon save/register behavior remains unchanged.

## Design

`Copy JSON` serializes the currently selected workflow draft with stable pretty-printed JSON and writes it to the system clipboard. The action works for starter drafts and daemon-loaded workflows because both are represented by the same editable workflow shape.

After a successful copy, the header save notice reports that workflow JSON was copied.

## Regression

`pipelines-ui.spec.ts` edits a workflow name, clicks `Copy JSON`, captures the clipboard write, parses the exported JSON, and verifies it contains the edited workflow shape.
