# Settings Default Model Save Lock

- Area: Corbina desktop Settings Providers pane
- Change: default routing provider/model controls are disabled while `update_config` is pending.
- Compatibility: loaded provider/model selection behavior is unchanged outside the pending save window.

## Design

Saving the default provider/model asks the daemon to persist configuration and then refreshes the parent settings snapshot. While that request is pending, the controls must not accept a second local selection that will be overwritten by the refresh from the earlier save.

`Settings.svelte` now disables both the Provider and Model selects whenever `modelSaving` is true. The Save button already used the same pending state.

## Regression

`settings-ui.spec.ts` delays `update_config`, clicks `Save default`, and verifies both default routing selects are disabled before the delayed response resolves.
