# Browser close-tab response ordering

Desktop Browser tab close responses are scoped to the tab-list and tab-creation
generations that issued the close.

Compatibility contract:

- Closing a tab increments the local tab-state generation before the daemon
  response returns.
- Opening a tab after a close increments a creation generation without marking
  concurrent open responses stale.
- A late close response from an older generation cannot replace the current tab
  list.
- The close fallback to `browser_close` remains best-effort on request failure.
- Session switches still invalidate pending close responses through the session
  generation.

Regression coverage lives in `apps/puffer-desktop/tests/desktop-ui.spec.ts`.
