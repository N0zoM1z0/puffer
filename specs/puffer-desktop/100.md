# Project Memory Previews

Project Detail memory data is currently synthesized from workspace/session
metadata. It must not be presented as editable files that exist on disk.

Contract:

- The Project Detail Memory tab labels synthesized entries as memory previews,
  not memory files.
- Preview detail headers show the source workspace/session path instead of a
  fabricated `.puffer/memory/*.md` path.
- The `Edit` control remains disabled until file-backed project memory editing
  is wired.
- Empty memory copy describes summaries, not missing on-disk files.

Regression coverage lives in
`apps/puffer-desktop/tests/workspace-ui.spec.ts`.
