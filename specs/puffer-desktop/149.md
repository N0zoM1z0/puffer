# Browser Close Fallback Session Guard

## Summary

The Browser pane now binds tab-close fallback cleanup to the agent session that
started the close request.

## Behavior

- `browser_agent close` captures the original root session and backend browser
  session before the async request starts.
- If the close request fails after the user has switched agents, the fallback
  `browser_close` cleanup is skipped.
- If the close request fails while the same agent session is still active, the
  fallback closes the originally targeted backend browser session.

## Compatibility

Normal tab close behavior is unchanged for the active agent. Late failures from
old agents can no longer close the newly selected agent's browser backend.
