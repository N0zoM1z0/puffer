# Pipeline Dependent Node Remove Confirmation

- Area: Corbina desktop Pipelines selected-agent editor
- Change: removing a node that downstream nodes depend on now requires an explicit confirmation.
- Compatibility: removing nodes with no dependents still completes from the header Remove action.

## Design

The inspector checks whether the selected node appears in any other node's `depends_on` list. If it does, the first Remove click shows an inline warning with the affected downstream node names and does not mutate the workflow.

The user can cancel to keep editing, or click `Remove anyway` to delete the node and remove its id from downstream dependency arrays.

## Regression

`pipelines-ui.spec.ts` selects the starter Codex node, clicks Remove, verifies the warning names the dependent Claude node and the Codex node remains selected, then confirms removal and verifies the graph no longer contains the Codex node.
