# Settings Provider Model Picker State Guard

The Settings Providers default-model picker keeps model errors and cached
model selections scoped to the selected provider.

Contract:

- A provider model load failure updates the visible error only if that provider
  is still selected when the failure resolves.
- Switching away from a provider while its model request is pending must not
  show that provider's late failure on the newly selected provider.
- Switching back to a provider with cached model descriptors hydrates
  `modelPickerModel` from the cached default or first model.
- A cached provider must not leave the Save default action permanently disabled
  because the previous provider switch cleared the selected model.

Regression coverage lives in
`apps/puffer-desktop/tests/settings-ui.spec.ts`.
