# Permissions rule validation

The desktop permissions editor validates the editable rule rows before saving
them as the daemon `tools` object.

Compatibility contract:

- Empty permissions are still valid and save as an empty tool map.
- A non-empty row must include a trimmed tool id.
- Duplicate trimmed tool ids block saving instead of overwriting an earlier
  visible row.
- Validation messages render in the Permissions pane and the Save button is
  disabled while validation fails.

Regression coverage lives in `apps/puffer-desktop/tests/settings-ui.spec.ts`.
