# Auth action stale snapshot ordering

Desktop auth actions are serialized and guarded by a latest-action generation.

Compatibility contract:

- API key login, OAuth login, external credential import, and logout share one
  auth action generation.
- Starting an auth action disables the other provider auth/import/logout
  controls until the active action resolves.
- A stale success response from an older auth generation cannot replace the
  current settings snapshot.
- A stale failure response from an older auth generation cannot replace the
  current auth error/status message.
- Daemon-scoped resets invalidate pending auth actions and clear busy flags.

Regression coverage lives in `apps/puffer-desktop/tests/settings-ui.spec.ts`.
