# Files LSP inspect ordering

Files pane LSP inspection results are scoped to the active file, root, symbol,
and request generation.

Compatibility contract:

- Starting a symbol inspection records a generation, file path, root, and
  selected symbol.
- A delayed inspection result cannot replace a newer symbol inspection.
- Clearing or changing the symbol invalidates older pending inspections.
- Loading and error state is cleared only by the latest inspection generation.

Regression coverage lives in `apps/puffer-desktop/tests/files-workspace-ui.spec.ts`.
