# Files save state after tab switches

The Files pane clears its pane-level save-in-progress state when a write
request finishes, even if the user has switched to another file tab.

Compatibility contract:

- Saving still writes the file that was active when the save started.
- Successful saves still refresh the saved file's parent directory.
- Save errors are shown only while the initiating file remains active.
- The shared `saving` flag is always cleared when the write request settles so
  another dirty active file can be saved.

Regression coverage lives in `apps/puffer-desktop/tests/files-workspace-ui.spec.ts`.
