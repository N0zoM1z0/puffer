# Terminal Close Optimistic Detach

- Area: Corbina desktop Terminal pane
- Change: closing a terminal tab detaches it from the UI immediately, before the daemon `pty_close` response returns.
- Compatibility: daemon close remains best-effort; failures were already ignored and do not re-open the tab.

## Design

The Terminal pane owns a live xterm input binding for the active PTY. If the user closes that PTY, the UI must stop accepting input for it immediately even when the daemon close call is slow.

`TerminalPane.svelte` now removes the tab, clears local sequence state, and switches/cleans up the active attachment before firing `closePty` asynchronously.

## Regression

`terminal-ui.spec.ts` delays `pty_close`, clicks `Close Terminal 1`, verifies the tab disappears immediately, types a key, and asserts no `pty_write` is sent to the closing PTY.
