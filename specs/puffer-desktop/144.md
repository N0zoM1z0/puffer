# Connect Project Remote Connect Rollback

The Connect Project remote flow restores the prior daemon client when the
remote daemon connection itself fails.

Contract:

- `doRemote` captures the current daemon handshake before starting remote
  connection.
- If `connectSshDaemon` throws, the modal attempts to switch back to the
  captured prior handshake before surfacing the error.
- Existing rollback behavior for clone/session-creation failures after a
  successful remote switch remains intact.
- A failed remote connection must not leave the shared daemon client pointed at
  an unreachable remote handshake.

Regression coverage lives in
`apps/puffer-desktop/tests/files-workspace-ui.spec.ts`.
