# Desktop pin latest-intent ordering

Desktop pin and unpin actions preserve the latest user intent when daemon
responses resolve out of order.

Compatibility contract:

- Each agent/workspace pin target has an independent request generation.
- Optimistic UI updates still apply immediately for responsive pin toggles.
- A success response from an older generation cannot replace the visible pin
  state from a newer generation.
- A failure response from an older generation cannot roll back a newer user
  action.
- Daemon-scoped resets clear pending pin generations.

Regression coverage lives in `apps/puffer-desktop/tests/workspace-ui.spec.ts`.
