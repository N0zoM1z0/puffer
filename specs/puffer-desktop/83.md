# Browser navigation failure scoping

Browser navigation failures are scoped to the tab and backend browser session
that submitted the URL.

Compatibility contract:

- Submitting a URL captures the active tab id, backend session id, target URL,
  and session generation before the daemon request starts.
- A delayed navigation failure updates only the initiating tab.
- If the user switches tabs before the failure returns, the newly active tab
  keeps its URL, status, and error state.
- Session switches still invalidate pending navigation failures.

Regression coverage lives in `apps/puffer-desktop/tests/desktop-ui.spec.ts`.
