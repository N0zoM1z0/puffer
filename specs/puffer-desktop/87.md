# MCP settings load generation

The Settings MCP server list is scoped to the current daemon/workspace source
generation.

Compatibility contract:

- Opening the MCP pane still lazy-loads server manifests once per source.
- Workspace/source refresh increments the MCP load generation and clears local
  MCP list state.
- A delayed `list_mcp_servers` response from an older generation cannot replace
  the current workspace's MCP server list.
- MCP add-server behavior remains unchanged and continues to refresh the local
  list from the daemon response.

Regression coverage lives in `apps/puffer-desktop/tests/settings-ui.spec.ts`.
