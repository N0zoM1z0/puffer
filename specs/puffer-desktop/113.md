# Connect Project Picker Pending Lock

- Area: Corbina desktop Connect Project modal
- Change: the embedded directory picker is disabled while project/session creation is pending.
- Compatibility: picker behavior is unchanged while idle or while only picker directory loading is pending.

## Design

The Connect Project modal can keep its directory picker open while the user starts session creation. Once submission begins, the submitted directory is fixed. The picker must not keep accepting path changes during that pending operation.

`ConnectProjectModal.svelte` now derives `pickerBusy` from the modal submission state and picker load state. The picker close button, path input, Go, Parent, Use this directory, and child directory rows all use that combined disabled state.

## Regression

`files-workspace-ui.spec.ts` opens the directory picker, delays `create_session`, starts the agent, and verifies the picker controls are disabled while the session creation request is pending.
