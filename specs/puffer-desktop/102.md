# Pipelines Local Draft Preservation

Pipelines local starter drafts must survive ordinary navigation and refresh
failures while workflow persistence is still unavailable.

Contract:

- Local starter draft edits are mirrored into browser local storage.
- Switching away from Pipelines and back restores the edited local draft.
- A workflow-list refresh that returns no daemon workflows keeps the current
  local draft instead of recreating the starter.
- A workflow-list refresh failure keeps the current local draft while showing
  the unavailable-daemon message.
- Real daemon workflow lists still replace local starter drafts.

Regression coverage lives in
`apps/puffer-desktop/tests/pipelines-ui.spec.ts`.
