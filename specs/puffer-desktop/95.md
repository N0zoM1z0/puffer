# Session Rename Response Ordering

Session title rename responses are scoped to the session and load generation
that initiated the request.

Compatibility contract:

- Saving a title sends the rename request for the originally selected session.
- A delayed rename response cannot replace a different session selected later.
- Failed delayed rename responses restore local state only while the renamed
  session is still selected.
- The workspace session list still refreshes after a successful rename.

Regression coverage lives in `apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
