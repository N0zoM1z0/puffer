# Pipeline Refresh Selection Preservation

- Area: Corbina desktop Pipelines workflow editor
- Change: refresh keeps the selected node when the selected workflow and node still exist in the refreshed snapshot.
- Compatibility: refresh still falls back to the first available node if the selected workflow or node was removed.

## Design

After a workflow snapshot refresh, the editor now resolves the active workflow from the current `workflowSlug`. It only changes `selectedNodeId` when that active workflow no longer contains the selected node.

This prevents a refresh from moving the inspector from a later selected node back to the workflow's first node.

## Regression

`pipelines-ui.spec.ts` loads two daemon workflows, selects the second workflow's second node, refreshes, and verifies the inspector remains on that selected node.
