# MCP Pending Action Labels

The Settings MCP form uses action-specific pending labels while the daemon
request is in flight.

Adding a new MCP server shows `Adding...` and editing an existing managed server
shows `Updating...`. Both states keep the same form lock behavior: fields and
the submit button remain disabled until the daemon request resolves.

Regression coverage lives in `apps/puffer-desktop/tests/settings-ui.spec.ts`
and asserts that the add form is locked with the `Adding...` submit state while
`add_mcp_server` is delayed.
