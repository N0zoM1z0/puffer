# Prompt Resolver Session Guard

Permission and user-question resolver results are scoped to the session that
submitted them.

Contract:

- Permission and question submissions capture the selected session id and
  session-load generation before dispatching to the daemon.
- Successful resolver responses update dismissed prompt state only if the same
  session is still selected.
- Failed resolver responses append retry/error UI only if the same session is
  still selected.
- Switching sessions while a resolver response is pending must not add prompt
  failure messages to the newly selected transcript.

Regression coverage lives in
`apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
