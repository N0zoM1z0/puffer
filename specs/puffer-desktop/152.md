# Agent Title Edit Focus

## Summary

Agent title editing now moves keyboard focus into the title input as soon as
edit mode opens.

## Behavior

- Clicking the title edit button switches to edit mode.
- After the input is mounted, the title field is focused and selected.
- Existing Enter, Escape, save, and cancel behavior is unchanged.

## Compatibility

Mouse users can still click or type normally. Keyboard users can activate edit
and immediately type the replacement title without tabbing back into the header.
