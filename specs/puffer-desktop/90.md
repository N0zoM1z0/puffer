# Turn start session scoping

Delayed `run_agent_turn` responses are scoped to the session that submitted the
message.

Compatibility contract:

- Starting a turn captures the selected session id and session-load generation.
- If the user switches sessions before `run_agent_turn` returns, the delayed
  response does not update the newly selected session's running state.
- Local optimistic user messages are added only while the originating session
  remains selected.
- App-level submission also refuses a second message while any turn is already
  starting or running.

Regression coverage lives in `apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
