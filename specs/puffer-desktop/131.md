# Terminal Attach Cancellation

The Terminal pane cancels pending attach work when the active PTY is closed or
when the session changes.

Contract:

- Closing the active terminal tab invalidates any pending replay, event
  subscription, input binding, and resize observer setup for that PTY.
- Switching sessions invalidates any pending attach work from the previous
  session before the new session restores or creates PTYs.
- Late `pty_replay` responses for closed PTYs must not create resize observers,
  write terminal output, or bind keyboard input.
- When no PTYs remain, the pane shows the safe empty state and does not display
  a terminal failure caused by stale attach work.

Regression coverage lives in
`apps/puffer-desktop/tests/terminal-ui.spec.ts`.
