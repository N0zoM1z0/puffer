# Browser Tabs Avoid External Favicons

## Summary

Browser tab labels no longer load page favicons directly into the Corbina
WebView.

## Behavior

- Browser tab metadata still tracks page URL, title, loading state, and
  connection state.
- Tab labels render the existing local loading/status dot instead of an
  external favicon image.
- Managed Chromium remains responsible for loading and rendering page content
  inside the screencast frame.

## Compatibility

This prevents the desktop WebView from making direct network requests for
browser-page resources while preserving Browser navigation and page rendering.
