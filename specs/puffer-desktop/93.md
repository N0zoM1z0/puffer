# Terminal UTF-8 output decoding

Terminal PTY output is decoded from base64 bytes as UTF-8 before being written
to xterm.

Compatibility contract:

- PTY data events remain base64-encoded bytes on the daemon protocol.
- The desktop renderer decodes those bytes with `TextDecoder`.
- Non-ASCII shell output renders as Unicode text instead of byte mojibake.
- Malformed frames remain best-effort skipped.

Regression coverage lives in `apps/puffer-desktop/tests/terminal-ui.spec.ts`.
