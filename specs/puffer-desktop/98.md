# Pipelines Starter Workspace

The Pipelines local starter draft must use the currently connected workspace
instead of a developer-machine path.

Contract:

- App-level workspace identity is passed into the Pipelines screen.
- When the daemon has no saved workflows, the starter draft seeds
  `pipeline.working_dir` from the current workspace root.
- If workspace identity arrives after the Pipelines screen mounts, the starter
  draft updates while it is still in starter-draft mode.
- Real daemon workflows are not overwritten by starter-draft workspace updates.

Regression coverage lives in
`apps/puffer-desktop/tests/pipelines-ui.spec.ts`.
