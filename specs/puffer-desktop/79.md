# Composer model picker provider selection ordering

The desktop composer model picker ignores stale provider-model responses after
the user picks a newer provider.

Compatibility contract:

- Opening the picker lazy-loads models only for the current provider.
- Provider switching has a monotonically increasing selection generation.
- A late `list_provider_models` success from an older provider selection cannot
  call `onChange` after a newer selection.
- A late provider-selection failure cannot replace the visible error for the
  current selection.
- Picking an explicit model row invalidates any pending provider-selection
  request.

Regression coverage lives in `apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
