# Workspace grouped session refresh generation

Desktop workspace refreshes are ordered by the latest requested grouped-session
load.

Compatibility contract:

- Every `refreshGroups()` invocation gets a monotonically increasing
  generation id.
- A late `list_grouped_sessions` success from an older generation does not
  replace the current `groups` state.
- A late failure from an older generation does not replace the current status
  message.
- The workspace loading indicator is only cleared by the currently active
  generation.
- Daemon-scoped resets invalidate pending grouped-session refreshes.

Regression coverage lives in `apps/puffer-desktop/tests/workspace-ui.spec.ts`.
