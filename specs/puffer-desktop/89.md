# Question answer in-flight state

User question prompts disable answer submission while a resolution request is
in flight.

Compatibility contract:

- The first Send answer action sends one `resolve_user_question` request.
- Additional clicks while the request is pending are ignored locally.
- Inputs and the send button are disabled while the answer is being sent.
- The prompt remains visible and retryable if the daemon rejects the answer.

Regression coverage lives in `apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
