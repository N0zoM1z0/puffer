# Terminal focus response ordering

Terminal tab attachment is scoped to the PTY that remains active after the
daemon focus request settles.

Compatibility contract:

- Selecting a terminal tab still updates the visible active tab immediately.
- A delayed `pty_focus` response may attach xterm only if that PTY is still
  active when the response returns.
- Keyboard input after rapid tab switching is sent to the last selected PTY.
- Session restoration and terminal creation continue to use the existing
  restore generation guards.

Regression coverage lives in `apps/puffer-desktop/tests/terminal-ui.spec.ts`.
