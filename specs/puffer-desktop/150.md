# Browser New-Tab Failure Ordering

## Summary

The Browser pane now ignores stale new-tab failures when a newer new-tab
request has already become the current tab creation attempt.

## Behavior

- Each new-tab request records its request order.
- A failed new-tab response updates the visible Browser error only when it is
  still the latest new-tab request for the active agent session.
- Older failed responses are ignored after a later new-tab request has
  succeeded or become current.

## Compatibility

Current new-tab failures still surface when no newer tab request superseded
them. Rapid tab creation no longer leaves a false error banner on the newer
active tab.
