# Files External Reload Draft Protection

The Files pane preserves user edits typed while an external file reload is
pending.

Contract:

- Filesystem change events may trigger a background reload for the active file
  only while the tab is clean.
- After the daemon returns file contents, the pane rechecks whether the tab has
  become dirty before applying the reload.
- If the user typed during the pending reload, the reload result is discarded
  and the draft remains visible.
- Clean tabs still accept external reload results and refresh their cached file
  contents.

Regression coverage lives in
`apps/puffer-desktop/tests/files-workspace-ui.spec.ts`.
