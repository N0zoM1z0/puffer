# New Agent Empty Provider State

## Summary

The New Agent modal now mirrors the Connect Project provider guard when the
settings snapshot contains credentials, but none of them are usable agent
providers.

## Behavior

- The modal still disables `Start agent` when no Codex/OpenAI/Anthropic/Claude/Puffer provider is authenticated.
- The provider area now explains that an agent provider must be connected before starting a session.
- No `create_session` RPC is sent while the provider list is empty.

## Compatibility

This is a renderer-only UI state change. Existing session creation and provider
canonicalization remain unchanged.
