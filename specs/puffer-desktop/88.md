# Approval resolution in-flight state

Permission approval buttons are disabled while a resolution request is in
flight.

Compatibility contract:

- The first selected approval choice sends one `resolve_permission` request.
- Additional clicks while the request is pending are ignored locally.
- The prompt remains visible and retryable if the daemon rejects the response.
- Successful resolution still dismisses the prompt through the parent state.

Regression coverage lives in `apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
