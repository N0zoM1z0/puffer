# Browser State Error Connectivity

Browser state events keep active-tab connectivity and toolbar availability in
sync.

Contract:

- A Browser state event with an `error` marks the target tab disconnected.
- If that tab is active, the pane-level `connected` flag is updated at the
  same time as URL, title, loading, status, and error state.
- Toolbar controls that depend on `browserControlsEnabled` become disabled
  after an active-tab Browser error.
- Non-error state events keep the active tab connected and leave the toolbar
  usable.

Regression coverage lives in
`apps/puffer-desktop/tests/desktop-ui.spec.ts`.
