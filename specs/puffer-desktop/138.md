# Credential Import Session Guard

Credential import failures during chat submission are scoped to the session
that initiated the turn.

Contract:

- Chat submission captures the selected session id and session-load generation
  before provider-auth checks begin.
- If a local external credential import is required, the submit path rechecks
  that same session after the import completes.
- A delayed import failure must not append provider-auth errors to a newly
  selected session.
- Successful imports may continue into `run_agent_turn` only when the original
  session is still selected.

Regression coverage lives in
`apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
