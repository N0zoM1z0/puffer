# Settings MCP Test Result State Guard

The Settings MCP Servers panel keeps test results scoped to the server list
generation that existed when the test started.

Contract:

- MCP load, save, remove, and daemon-source reset operations advance the MCP
  mutation generation.
- A pending `test_mcp_server` result updates `mcpSaved` or `mcpError` only if
  the generation still matches and the tested server still exists.
- Removing a server while its test is pending keeps the removal status visible
  and ignores the late validation result.
- The active testing indicator is cleared for the tested server when the
  request completes, even when its result is ignored as stale.

Regression coverage lives in
`apps/puffer-desktop/tests/settings-ui.spec.ts`.
