# Agent Title Edit Session Boundary

## Summary

Agent title edit state is now scoped to the session where editing started.

## Behavior

- Starting title edit records the active session id.
- Switching to a different session exits title edit mode and clears the edit
  session marker.
- Saving or cancelling title edit clears the marker for the completed edit.
- Existing title save, cancel, and focus behavior is unchanged for the same
  session.

## Compatibility

Users can still edit a session title in place. The change only prevents an
unfinished edit draft from appearing on, or being saved from, a different
selected session.
