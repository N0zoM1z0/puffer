# Browser focus failure scoping

Browser tab focus failures are scoped to the tab and session generation that
issued the focus request.

Compatibility contract:

- Selecting a Browser tab still updates the active tab immediately.
- A failed `browser_agent` focus request may show an error only while the same
  tab remains active in the same session generation.
- Switching to another tab before a delayed focus failure returns leaves the
  active tab's error state unchanged.
- Fake daemon delayed responses apply to success and failure replies so
  Playwright can reproduce stale error ordering.

Regression coverage lives in `apps/puffer-desktop/tests/desktop-ui.spec.ts`.
