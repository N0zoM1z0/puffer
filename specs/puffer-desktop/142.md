# Settings MCP Save State Guard

The Settings MCP Servers pane scopes save/remove results to the settings source
and MCP list generation that started the operation.

Contract:

- MCP save and remove operations capture operation generations before awaiting
  daemon responses.
- A delayed save/remove success or failure is ignored after a workspace/source
  refresh advances the MCP mutation or operation generation.
- Settings-source reset clears pending MCP saving, removing, testing, editing,
  status, and form state.
- After refreshing to another workspace, the MCP pane can load that workspace's
  server list without old add/update/remove responses reintroducing prior
  servers.

Regression coverage lives in
`apps/puffer-desktop/tests/settings-ui.spec.ts`.
