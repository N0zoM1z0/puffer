# Connect Project Picker Mode Reset

The Connect Project modal clears Local-only directory picker state when the
user switches to Remote mode.

Contract:

- Local/Remote tab changes are routed through `setMode`.
- Switching to Remote closes the local directory picker.
- Switching to Remote advances the picker load generation so delayed
  `list_dir` responses cannot repopulate the hidden picker.
- Switching to Remote clears picker loading, error, and entry state.

Regression coverage lives in
`apps/puffer-desktop/tests/files-workspace-ui.spec.ts`.
