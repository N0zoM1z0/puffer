# Files Pane Concurrent Save State

- Area: Corbina desktop Files pane
- Change: file save pending state is tracked per file path instead of as one pane-wide boolean.
- Compatibility: existing single-file save behavior is unchanged; dirty controls for the active file still show `Saving...` only for that file.

## Design

The Files pane can have multiple open editor tabs. A delayed save for one file must not hide or disable the Save control for another dirty file after the user switches tabs.

`FilesPane.svelte` now stores a `Set<string>` of paths with pending saves. The active editor derives its saving state from `activePath`, so a pending write for `main.rs` does not block an independent write for `lib.rs`.

## Regression

`files-workspace-ui.spec.ts` delays a save for `/tmp/puffer/src/main.rs`, switches to `/tmp/puffer/src/lib.rs`, edits it, and verifies the second Save button is immediately enabled and sends an independent `write_file` request.
