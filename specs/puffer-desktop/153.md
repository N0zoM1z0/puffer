# Agent Find Session Refresh

## Summary

Agent detail find now recomputes matches when the visible session content
changes while the find box stays open.

## Behavior

- Switching from one session to another keeps the find box open.
- Existing marks are cleared from the old DOM before the new content is
  searched.
- The match count and previous/next controls reflect the newly selected
  session.
- Stale asynchronous find refreshes are ignored after a newer refresh or close.

## Compatibility

The keyboard shortcut and find buttons are unchanged. The fix only refreshes
derived find state when session/detail content changes, so existing search input
remains available across navigation without showing stale counts.
