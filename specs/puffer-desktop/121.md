# Pipeline Node Id Rename

- Area: Corbina desktop Pipelines selected-agent editor
- Change: node ids can be edited with validation and dependency rewrites.
- Compatibility: unchanged node ids are inert; duplicate or empty ids cannot be applied.

## Design

The selected-agent inspector now renders Node id as an editable draft plus an explicit Apply action. The draft validates non-empty and unique ids before applying.

Applying a new id updates the selected node id and rewrites every `depends_on` entry that referenced the old id. This keeps graph wiring stable after a rename.

## Regression

`pipelines-ui.spec.ts` renames the Claude reviewer node, exports the workflow JSON, and verifies the Puffer node's dependency points at the new id. A second test verifies empty and duplicate ids disable Apply with inline validation.
