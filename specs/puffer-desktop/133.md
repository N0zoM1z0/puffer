# Browser New-Tab Failure Session Guard

The Browser pane ignores late new-tab failures from sessions that are no
longer active.

Contract:

- New-tab requests capture the active root session at submit time.
- Successful responses apply only if the pane generation, tab-state version,
  and root session still match the request.
- Failed responses apply only if the pane is still viewing the same root
  session that submitted the request.
- Switching to another agent before a delayed tab-open failure resolves must
  not render an error banner or change toolbar state in the new agent.

Regression coverage lives in
`apps/puffer-desktop/tests/desktop-ui.spec.ts`.
