# Browser Address Navigation Without Form Submit

## Summary

The Browser toolbar no longer uses an HTML form for address navigation.

## Behavior

- Pressing Enter in the Browser address input invokes the managed browser
  navigation request directly.
- The toolbar is rendered as a non-submitting container.
- Browser control buttons remain explicit `type="button"` controls.
- Existing navigation state, tab state, and daemon request payloads are
  unchanged.

## Compatibility

This avoids WebView-level form submission and page reload behavior while keeping
the same user-facing address bar interaction.
