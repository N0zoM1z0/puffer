# Codex Local Credential Turn Import

Codex chat sessions may continue when a local Codex CLI credential is detected
but has not yet been imported into Puffer's auth store.

Contract:

- The chat composer treats a provider as usable when it is authenticated in the
  settings snapshot or has a matching external credential candidate.
- On the first turn for an unauthenticated but importable provider, the shell
  calls `import_external_credential` before `run_agent_turn`.
- Provider aliases are compared canonically, so a Codex session can import the
  `openai` credential discovered from `~/.codex`.
- If the import fails, the turn is not sent and the existing provider reconnect
  error path remains active.
- Runtime execution still reads Puffer's auth store; it does not read
  `~/.codex` directly during a turn.

Regression coverage lives in
`apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
