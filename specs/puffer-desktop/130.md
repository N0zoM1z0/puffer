# Settings Snapshot And Credential Imports Use Daemon

The desktop API layer uses the active Puffer daemon for settings snapshots and
external credential import flows whenever a daemon connection is available.

Contract:

- `loadSettingsSnapshot` first requests `load_settings_snapshot` from the active
  daemon client and falls back to Tauri invoke only when the daemon is
  unavailable.
- `listExternalCredentials` first requests `list_external_credentials` from the
  active daemon client and falls back to Tauri invoke only when needed.
- `importExternalCredential` first requests `import_external_credential` from
  the active daemon client so imported credentials are written to the same auth
  store used by agent turns.
- Browser/Vite previews without Tauri continue to use a configured daemon or
  safe mock/empty fallbacks.

Regression coverage lives in
`apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
