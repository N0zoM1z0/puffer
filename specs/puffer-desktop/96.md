# Workspace Session Search Coverage

Workspace project session derivation includes every daemon session in each
folder group.

Compatibility contract:

- The workspace project list is still derived from daemon folder groups.
- Agent cards are created for all sessions in a folder, not only the first six.
- Workspace search considers sessions beyond the first six in a project.
- Project counters reflect the same complete session set used for rendering.

Regression coverage lives in `apps/puffer-desktop/tests/workspace-ui.spec.ts`.
