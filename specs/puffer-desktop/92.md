# Freeform user questions

User question requests without predefined options render as answerable
freeform prompts.

Compatibility contract:

- `user-question-request` normalization keeps questions whose options list is
  empty.
- The question prompt shows the question text and custom-answer input.
- Submitting a freeform-only question sends the typed answer under the visible
  question key.
- Existing option-based and multi-select question behavior is unchanged.

Regression coverage lives in `apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
