# Settings MCP Add Pending State

The MCP server add form must not accept a second draft while an
`add_mcp_server` request is pending.

Contract:

- ID, name, transport, scope, target/URL, arguments, and description controls
  are disabled while `mcpSaving` is true.
- The Add server button remains disabled and shows the pending label during the
  save request.
- The submitted form can still be reset after the daemon confirms the add,
  because no later draft can be typed during the pending window.

Regression coverage lives in
`apps/puffer-desktop/tests/settings-ui.spec.ts`.
