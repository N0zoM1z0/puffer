# Codex Browser Tool Routing

## Summary

Corbina now starts Codex app-server with Codex native browser tools disabled and
with Playwright MCP explicitly configured.

## Behavior

- The desktop daemon still creates or reuses the session's managed Browser tab
  before a Codex turn.
- The managed Browser tab's CDP HTTP endpoint is passed to Playwright MCP when
  available.
- Codex native `browser_use`, `browser_use_external`, and `in_app_browser`
  tools are disabled for the app-server child process.
- If Corbina cannot provide a CDP endpoint, Playwright MCP still starts in
  headless mode.

## Compatibility

This keeps browser automation inside Corbina's managed Chromium surface instead
of exposing Codex's separate browser daemon path, which is not launched by the
desktop backend.
