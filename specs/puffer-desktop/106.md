# Settings Permissions Save Pending State

The permissions editor must not accept new local rule edits while a
`save_permissions` request is pending.

Contract:

- Existing permission tool inputs, mode selectors, and remove buttons are
  disabled while `permissionSaving` is true.
- The Add rule button is disabled while a save is pending.
- The Save button keeps the existing pending disabled behavior and shows the
  saving label.
- The daemon response may replace the submitted rows and clear the dirty flag
  only after the UI has prevented newer edits during the pending window.

Regression coverage lives in
`apps/puffer-desktop/tests/settings-ui.spec.ts`.
