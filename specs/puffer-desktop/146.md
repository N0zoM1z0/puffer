# Composer IME Enter Handling

## Summary

The chat composer now ignores Enter keydown events while an input method editor
composition is active.

## Behavior

- `KeyboardEvent.isComposing` prevents the composer from submitting a prompt.
- `keyCode === 229` is also treated as composition for browser compatibility.
- Normal Enter submission and Shift+Enter newline behavior are unchanged.

## Compatibility

This change is limited to the renderer textarea key handler. It does not alter
daemon turn submission payloads or provider routing.
