# Workspace Duplicate Project Labels

Workspace project rows must remain distinguishable when different folders share
the same basename.

Contract:

- Each project row shows the full folder path as secondary text next to the
  basename label.
- Workspace search continues to match the full project path.
- Duplicate basenames can be filtered to one project by typing a unique parent
  path segment.
- Existing project actions still target the same folder path.

Regression coverage lives in
`apps/puffer-desktop/tests/workspace-ui.spec.ts`.
