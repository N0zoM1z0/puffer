# Files Late Tab Restore

## Summary

The Files pane now ignores a delayed persisted-tab restore when the user has
already changed the tab set in the current session.

## Behavior

- Session/root reset increments the local tab mutation generation.
- Opening or closing a file tab increments the same generation.
- `load_file_tabs` results are applied only if no local tab mutation occurred
  while the restore request was pending.

## Compatibility

Normal saved-tab restoration still applies when the user waits for it. Manual
file opens, linked-file opens, and tab closes keep precedence over stale
restore responses.
