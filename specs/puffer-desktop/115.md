# Pipeline Required Field Validation

- Area: Corbina desktop Pipelines editor
- Change: required workflow, trigger, and selected-agent fields now show inline validation when cleared.
- Compatibility: local draft editing remains local-only; validation does not add daemon save/export behavior.

## Design

The editor validates empty required text fields directly in the form. Pipeline name, slug, working directory, subscription source topic, subscription pattern, cron expression, agent name, model, tools, and prompt render inline errors and `aria-invalid` when their current value is empty.

Slug and cron editing no longer auto-substitutes defaults while the user is typing. This allows the UI to represent the user's cleared field and show the corresponding validation error instead of silently replacing the value.

## Regression

`pipelines-ui.spec.ts` clears all required pipeline, trigger, and selected-agent fields and asserts that the inline validation messages are visible.
