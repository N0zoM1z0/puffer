# Connect project requires an agent provider

The desktop Connect Project modal cannot create an agent unless there is at
least one authenticated provider that can run agent turns.

Compatibility contract:

- The provider radio group continues to show only authenticated personal agent
  providers.
- When no provider option is available, the modal renders an explicit provider
  connection hint.
- Local and remote submit buttons stay disabled while no provider option is
  available, even when destination fields are valid.
- The modal no longer falls back to `openai` when no authenticated agent
  provider is visible.
- Disabled submit state must not emit `create_session`.

Regression coverage lives in `apps/puffer-desktop/tests/files-workspace-ui.spec.ts`.
