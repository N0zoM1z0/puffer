# Pipelines Provider Switch Preservation

Changing the selected pipeline node provider must not erase user-entered agent
configuration.

Contract:

- Provider switching updates the node provider type.
- Agent name, model, and tools are replaced with the new provider defaults only
  when the old values still match the prior provider defaults.
- User-customized agent name, model, tools, and prompt are preserved.
- The default starter node still receives appropriate defaults when switching
  provider before customization.

Regression coverage lives in
`apps/puffer-desktop/tests/pipelines-ui.spec.ts`.
