# Settings Permissions Save State Guard

The Settings Permissions pane scopes save results to the settings source that
started the save.

Contract:

- `save_permissions` captures the current permission load generation before
  awaiting the daemon response.
- A delayed save success or failure is ignored after a workspace/source refresh
  advances the permission generation.
- Settings-source reset clears `permissionSaving` in addition to rows, errors,
  dirty state, and load state.
- After refreshing to another workspace, the Permissions pane can load and edit
  that workspace's rules without being blocked by an old save.

Regression coverage lives in
`apps/puffer-desktop/tests/settings-ui.spec.ts`.
