# Model Picker Failed Provider Switch

## Summary

The agent model picker now preserves the current provider/model route when a
new provider's model list cannot be loaded or is empty.

## Behavior

- Provider switching still lazy-loads the target provider's models.
- A failed or empty load keeps the current provider and model selected.
- The picker surfaces the existing load error message and does not send an empty model id through `onChange`.

## Compatibility

This is a renderer-only guard. Successful provider switches and explicit model
selection continue to call the same `onChange(providerId, modelId)` contract.
