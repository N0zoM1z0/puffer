# Modal Focus Management

Workspace-level modals must behave as modal dialogs for keyboard users.

Contract:

- Opening New agent, Connect project, or Switch workspace moves focus into the
  dialog.
- Dialogs can mark a preferred initial control with
  `data-modal-initial-focus`.
- Tab and Shift+Tab cycle within the dialog instead of escaping to background
  controls.
- Escape closes the dialog when the modal is not busy.
- Closing a dialog restores focus to the opener when it is still mounted.

Regression coverage lives in
`apps/puffer-desktop/tests/files-workspace-ui.spec.ts` and
`apps/puffer-desktop/tests/workspace-ui.spec.ts`.
