# Pipeline Wiring Cycle Guard

- Area: Corbina desktop Pipelines editor
- Change: the wiring panel rejects dependency edits that would create a cyclic workflow graph.
- Compatibility: existing valid dependency edits are unchanged, and existing dependencies remain removable even if the loaded workflow is already invalid.

## Design

The Pipelines editor now evaluates whether a candidate dependency would make the selected target reachable from its dependency chain. Dependency checkboxes that would add a cycle are disabled, and "Send selected output to" actions use the same guard.

Existing checked dependencies are not disabled by the guard. This keeps malformed or imported cyclic workflows repairable from the UI.

## Regression

`pipelines-ui.spec.ts` opens the starter workflow, selects the upstream Codex node, and verifies the reverse dependency that would create a Codex <-> Puffer cycle is disabled and remains unchecked.
