# Composer Submit Draft Preservation

The chat composer must not discard a newer draft typed while a previous prompt
submit is still waiting for the daemon to accept the turn.

Contract:

- Submit captures the exact textarea content used for the outgoing prompt.
- A successful submit clears the composer only when the textarea still matches
  that captured content.
- If the user typed a newer draft during the pending submit, the newer draft
  remains visible after `run_agent_turn` resolves.
- Failed turn-start behavior continues to preserve the submitted draft and avoid
  creating a local unsent user row.

Regression coverage lives in
`apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
