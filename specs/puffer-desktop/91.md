# Stop turn cancellation state

The chat Stop button treats `cancel_turn` as a single in-flight action.

Compatibility contract:

- Clicking Stop sends one cancellation request for the active turn id.
- Repeated clicks while the request is pending do not send duplicate
  `cancel_turn` requests.
- The Stop button is disabled while cancellation is in flight.
- Cancellation failures are surfaced in the transcript as retryable errors.

Regression coverage lives in `apps/puffer-desktop/tests/chat-session-ui.spec.ts`.
